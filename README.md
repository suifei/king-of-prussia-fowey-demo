# King of Prussia Fowey demo — 给 SuiFei

这是一页给店老板看的门面站 demo，不是上线站，也不是报价单。文件在 `/workspace/demos/king-of-prussia-fowey/index.html`。用手机打开即可。以后 GitHub Pages：https://suifei.github.io/king-of-prussia-fowey-demo/

没有联系店家。没有自称程序员。页脚只有店名和 Fowey。下面一小排「Also around」是别的店，不是作品集，也不含本店。

他们已经有自己的站。这页不是去「替换官网」，也不是去贬现在那一页。是让老板在自己的手机上先看见：Town Quay、六间河景房、Scott Williams 的厨房、周一休息那张钟点表、Carter's —— 像一间河口码头上的客栈，而不是 Padstow 那两家木头/石板 pub。

都来自同目录 `source.md`（2026-08-29 搜集），页面上能对上的是：

- 店名：The King of Prussia
- 地址：3 Town Quay, Fowey PL23 1AT
- 电话：01726 211061（`tel:+441726211061`）
- 邮箱：enquiries@thekingfowey.co.uk
- 码头上几百年的 historic pub with rooms；修复后的老味道、一点现代舒服；镇中心
- Teresa 的团队；主厨 Scott Williams；proper British food；本地食材；酒吧；欢迎本地人和访客
- 楼上六间河景房、en suite、super king 和 double。步行 / 船 / 公交即可
- 钟点认 eat 页时间表：周一休（银行假日除外）；周二至周六餐 12–9、吧 12–close；周日烤餐 12–5pm、吧 12–close。不把他们那句「open 7 days」写成每天都开
- 订桌：最多六位；七位以上打电话或发邮件；两小时；靠窗不保证；不接受只喝酒订桌

- 活动只写从夏日烧烤到圣诞派对，没有假日历
- Webbsters Fish & Chips 在 Webb Street（他们自己活动页上的），带他们写的钟点
- 评分只写约数：TripAdvisor 约 4.3 / 约 735。Google 本轮没核，没写。没有编顾客原话

按钮只有打电话和发邮件。没有假表单。

## 哪些是占位 / 故意没写

- **菜名和价格**：eat 页只有 SampleMenu 一类标签，当天没抽出菜。厨房不列菜。
- **thekingfowey.co.uk**：没有链成「我们的官网」。现站是 Wix，浏览器标题还写 **HOME | Thekingfowey**——只记在 `source.md`，不要当攻击念给老板听。
- **订位 / 订房系统**：他们有。这页只留电话和邮箱，不装表单，也不链一个假装能代订的按钮。
- **取消费 / 刷卡担保 / £25/head**：政策存在，店头 demo 不放。
- **房间名、房价**：没编。
- **Carter's 钟点**：页上没有，空着。
- **Google 星级**：本轮 Maps HTML 未核，没写。
- **顾客引言**：首页有一条，没用。

## 建议怎么开口

先把手机递过去，让他自己往下划。不要先讲技术，不要说「我是做网站的」，也不要贬他们现在那一页。

可以这样说：

> 按你们 Town Quay 上的店名、六间看河口的客房、主厨 Scott Williams，和厨房那张钟点表，做了一页给您看。周一休息，银行假日除外；周二到周六吃饭十二点到九点。订桌最多六位，七位以上打电话或发邮件。房间没有标价，也没有网上表格。Carter's 只写了开季，钟点空着——你们网上也没写。电话和邮箱按下去就能打、能发。

等他看完，再问两件具体的：

1. 菜单要不要换成厨房正在用的（这份完全没菜名）。
2. 订桌 / 订房是继续电话和邮件，还是以后要接到这页上。Carter's 的钟点，有就补一句。

他如果觉得不像，就收起来。这页的用处是让他先看见自己的店，不是说服他买网站。
